# DealerLoft Marketplace Assistant (browser extension)

This extension fills in Facebook's own "Create vehicle listing" form using
the details from a listing in DealerLoft, so you only have to check it over
and click Facebook's own **Publish** button. It never touches your Facebook
account directly and never posts anything on its own — it just types into
the page for you, the same as if you'd typed it yourself.

It isn't published to the Chrome Web Store yet, so installing it takes a
few extra clicks the first time. After that, it just works in the
background.

## Install it (one time, about 2 minutes)

1. In DealerLoft, open **Extension** in the sidebar and click **Download
   extension**.
2. Find the downloaded file (usually in your Downloads folder) and unzip
   it — on Windows, right-click it and choose "Extract All"; on a Mac,
   just double-click it. Move the `dealerloft-extension` folder somewhere
   it can stay, like Documents: Chrome loads it from there every time.
3. Open Chrome and go to `chrome://extensions` (type that into the address
   bar and press Enter). Edge and Brave work too.
4. In the top-right corner, turn on **Developer mode**.
5. Click **Load unpacked** (top-left).
6. Select the `dealerloft-extension` folder and click **Select Folder**
   (or **Open**).

You should now see "DealerLoft Marketplace Assistant" in your list of
extensions, and DealerLoft's Extension page shows it as Installed. That's
it — nothing else to configure.

## Using it

1. Make sure you're logged into Facebook in that same Chrome browser, like
   normal.
2. In DealerLoft, open a listing and click **Post to Facebook Marketplace**.
3. A new tab opens on Facebook's own vehicle listing page, already filled
   in with the year, make, model, price, mileage, and other details.
4. Check everything over — especially the photos — fix anything that
   needs it, then click Facebook's own **Publish** button yourself.
   DealerLoft never clicks Publish for you.

If a field didn't get filled in, a small box in the corner of the page
will tell you which ones — just fill those in by hand. Facebook changes
its site sometimes, so occasionally a field name needs to be updated;
if you notice some fields consistently not filling in, let us know what
they are and we'll fix it.

## Updating it later

DealerLoft's Extension page tells you when a newer version is out.
Download it, unzip it, and replace the files in your existing
`dealerloft-extension` folder. Then click the reload arrow on the
extension's card in `chrome://extensions`. Keep using the same folder:
Chrome treats a different folder as a different extension.

## Uninstalling it

Go to `chrome://extensions`, find "DealerLoft Marketplace Assistant," and
click **Remove**.
